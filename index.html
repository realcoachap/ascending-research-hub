The principle

The hub should feel like a professional directory: tools, education, verification, and commerce each have a clear purpose. The separation is real because the wording, UX, and links keep each lane disciplined.

Education laneGeneral literacy, mechanisms, terms, and research context. No buying pressure.
Calculator laneArithmetic-only outputs: concentration, unit mapping, reverse volume math.
Store laneResearch-use-only catalog, COAs, batch details, storage, terms. No protocol or dose language.
Trust architecture

Not a directory. A decision surface.

PeptideCritic sets a useful transparency bar with pricing, vendor data, COAs, and reviews. Ascending should feel more premium: education first, tools second, verification third, commerce only when the trust layer is visible.

Separation by designEducation, tools, verification, and shop each have a disciplined lane.
Verification-forwardCOA checks are treated as a primary navigation item, not fine print.
Premium restraintCleaner copy, fewer claims, stronger visual hierarchy, more confidence.

Launch sequence

  • First live link: Research Concentration Calculator.
  • COA / batch verification now routes to a dedicated lab directory page.
  • Education library preview is now linked; next polish pass can add profile pages, glossary search, and newsletter capture.
  • Shop preview is now separated; final commerce routing waits until compliance copy, COA handling, and product labels are locked.
