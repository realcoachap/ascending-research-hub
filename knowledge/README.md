# Theo Knowledge Base

v0.1.0 — Theo 🧪 — 2026-05-22

WHY: Curated source brain for Ask Theo so answers can synthesize trusted papers, researcher content, transcripts, labels, COAs, and vetted education sources instead of relying only on a generic model.

## Source tiers

- `peer_reviewed` — PubMed/DOI papers, reviews, official journal material.
- `clinical_reference` — established medical/scientific reference pages.
- `researcher_media` — long-form researcher/clinician education from YouTube, Rumble, X, podcasts, etc.
- `product_label` — labels, COAs, product pages, batch documentation.
- `social_claim` — social clips/posts that need verification before being treated as reliable.

## Rule

Theo may summarize and compare sources, but should clearly distinguish:

- what a peer-reviewed paper says
- what a researcher/creator claims
- what a product label/COA says
- what is still uncertain or unsupported

No source becomes medical advice.
